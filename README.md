# Lab 02 — GraphQL Video Service

Built for the **ENSAM Casablanca** System Design module.

A small GraphQL service for managing videos and creators.

## Tech Stack

- **Framework:** Spring Boot
- **Language:** Java 17
- **Database:** H2

## Quick Start

> [!NOTE]
> Requires JDK 17.

```bash
./mvnw spring-boot:run
```

Open [GraphiQL](http://localhost:8090/graphiql) to try the API.
